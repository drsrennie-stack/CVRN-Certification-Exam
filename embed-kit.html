Embed Kit

Copy-paste snippets for putting the CVRN tools inside Kajabi, Canvas, or any host page. The tools already send their height to the parent; this page gives you the receiving half plus the iframe markup.

How it works

  1. Each tool measures its own height and posts it to the parent window as {type:'cvrn:height', id:'...', height:1234}, on load, on resize, on any click, and whenever a ResizeObserver fires.
  2. cvrn-embed.js sits on the host page, listens for that message, and sets the matching iframe's height. It only accepts messages from origins on its allow list.
  3. The result is a tool with no inner scrollbar. The host page scrolls, the iframe does not.

Step one, set your base URL

Change this and every snippet below updates. Whatever you set here also needs to appear in the ALLOWED_ORIGINS array inside cvrn-embed.js.

Step two, add the resizer once

In Kajabi: Settings → Site Details → Custom Code → Footer. Add it once for the whole site, not once per page.

Site-wide footer code

<script src="BASEcvrn-embed.js" defer></script>

If you would rather not host the file, paste the contents of cvrn-embed.js between <script> tags in the same footer block instead.

Step three, drop an iframe where you want the tool

In Kajabi, use a Custom Code block on the page or lesson. One block per tool.

Mastery OS plan, gap finder, exams

<iframe
  data-cvrn-embed
  src="BASEcvrn-mastery-os.html"
  title="CVRN Mastery OS"
  style="width:100%;border:0;height:1400px;display:block"
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade"></iframe>

The starting height is only what shows before the first message arrives. Set it close to the real height so the page does not visibly jump if a learner is on a slow connection.

Things that will bite you

Mixed content. The host page and the tool must both be https, or the browser blocks the frame silently.

Origin allow list. If the height never updates, the origin in ALLOWED_ORIGINS does not match where the tools are actually served. It must be scheme plus host with no trailing slash, for example https://drsrennie-stack.github.io.

Storage. Progress, plans, and read state are saved in the browser under the iframe's own origin, not the host page's. A learner who studies on the Kajabi page and then opens the tool directly will see two separate sets of progress.

Links out. The study tool cards use target="_top", so clicking one navigates the whole Kajabi page rather than loading a tool inside a tool.

Printing. Browsers print the host page, not the framed document. For the study notes, give learners a direct link alongside the embed so Print or Save as PDF produces the full document.

Live check

This page runs the resizer on itself. If the frame below sizes to its content with no inner scrollbar, the pair is working.
